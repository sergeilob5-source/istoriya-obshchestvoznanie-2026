# Учебный портал «История и Обществознание · 2026»

Сайт для обучения по истории (5–11 классы) и обществознанию (9–11 классы)
по действующим на 2026 год программам РФ (ФГОС, ФОП, единые государственные
учебники под ред. В. Р. Мединского, А. О. Чубарьяна, А. В. Торкунова),
с разделом подготовки к ЕГЭ и ОГЭ 2026.

Доступ к сайту — только по логину и паролю, которые выдаёт администратор.

## Запуск

Нужен только Python 3 (никакие библиотеки ставить не нужно):

```
python server.py
```

Сайт откроется по адресу http://localhost:8741
(другой порт: `python server.py 8080`).

## Вход и учётные записи

- При первом запуске автоматически создаётся администратор:
  **логин `admin`, пароль `admin2026`**.
- Сразу после первого входа смените пароль администратора в админ-панели
  (раздел «Сменить пароль»).
- Учётные записи учеников создаются в админ-панели: http://localhost:8741/admin
  (ссылка «Админ-панель» видна только администратору).

## Публичный сайт (GitHub Pages) со входом по паролю

Сайт опубликован на GitHub Pages:
https://sergeilob5-source.github.io/istoriya-obshchestvoznanie-2026/

GitHub Pages не выполняет серверный код, поэтому защита устроена так:

- В репозиторий попадают только **зашифрованные** страницы
  (HMAC-SHA256-CTR + encrypt-then-MAC, ключи из PBKDF2-SHA256, 200 000 итераций).
- Посетитель вводит логин и пароль — страница расшифровывается прямо
  в его браузере (WebCrypto). Без пароля содержимое прочитать нельзя.
- Публикация: админ-панель → кнопка **«Опубликовать на GitHub»**
  (или `python server.py publish`). При каждой публикации создаётся новый
  мастер-ключ, поэтому удалённый пользователь теряет доступ после
  следующей публикации.
- После добавления/удаления пользователей или правки страниц в `pages/`
  нужно нажать «Опубликовать на GitHub» — иначе публичный сайт не изменится.

## Файлы

| Файл | Назначение |
|------|-----------|
| `pages/*.html` | Исходные (открытые) страницы сайта. В git НЕ попадают — сделайте их резервную копию |
| `index.html` и др. в корне | Зашифрованные версии для GitHub Pages (генерируются при публикации) |
| `protected_template.html` | Шаблон страницы входа с расшифровкой |
| `style.css` | Оформление |
| `server.py` | Локальный сервер: вход, админ-панель, публикация |
| `users.json` | Локальная база пользователей (хеши и ключи-обёртки). Не публиковать и не удалять |

## Безопасность

- Пароли хранятся хешированными (PBKDF2-SHA256, 200 000 итераций, соль на пользователя).
- Сессии живут в памяти сервера: перезапуск сервера разлогинивает всех.
- `server.py`, `users.json` и папка `pages/` наружу не отдаются и в git не попадают.
- Публичный `users_pub`-блок в страницах содержит только соли и зашифрованный
  мастер-ключ; подобрать можно только слабый пароль перебором — выдавайте
  ученикам пароли не короче 8–10 символов.
- Ссылки «поделиться» недостаточно: у человека должен быть и логин с паролем.
